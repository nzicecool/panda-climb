Built for Smooth 60 FPS & Privacy

Modern native Android engineering with zero external tracking or account gates.

Native OpenGL ES 2.0

Procedural VBO geometry, Blinn-Phong + Fresnel rim shaders, dynamic tracking camera, and GC-free matrix math run directly inside Compose via GLSurfaceView.

Procedural Synth Audio

Synthesizes jump sweeps, spring bounces, power-up fanfares, and barrel smashes live on AudioTrack without large bundled audio files.

On-Device Room Database

All tower unlocks, star ratings, high scores, nicknames, and career stats stay privately on your phone in local SQLite storage—no login or cloud upload.

Build & Publish from Source

Clone the Android project (API 24–36, Kotlin + Jetpack Compose + Room + KSP), run the simulation unit tests, or publish this /docs folder directly on GitHub Pages.

$ gradle :app:testDebugUnitTest --tests "com.example.GameSimulationTest"
